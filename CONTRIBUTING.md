# Contributing

Thanks for helping out.

- Open an issue before starting larger changes.
- Work on a branch and open a pull request against `main`.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages, for example `fix: handle empty frame`.
- Keep pull requests small and focused.
- Never commit secrets, personal data, or device serial numbers.
- Do not copy code from projects with an incompatible license. Protocol facts are fine; code is not.

## Adding a new device

Open a [device report](../../issues/new?template=device_report.yml) with your cooler model and USB ID.

## Code of conduct

By taking part you agree to the [code of conduct](CODE_OF_CONDUCT.md).
