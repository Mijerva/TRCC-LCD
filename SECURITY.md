# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through the **Security** tab of this repository ("Report a vulnerability").

Include what you found, how to reproduce it, and which version you used. You should get a reply within 7 days.

## Supported versions

Only the latest release gets security fixes.

## Scope

In scope: the app, its installer and release files, and how it handles files and USB data.

Out of scope: the cooler firmware and Thermalright's own software.
